# Roadmap

This kit is maintained as-needed, not on a fixed release schedule — new items are added when a real review surfaces something the checklist should have caught.

## Now

- [ ] Grow the Reviewers/Contributors list past the first external PR
- [ ] Add a "good-first-issue" pass so newcomers have a clear place to start (see [open issues](https://github.com/projekta2/pr-review-canvas/issues))
- [ ] Short video walkthrough of the interactive checklist (embedded in the README)

## Planned

- [ ] Language-specific appendices (JS/TS, Python, Go) with checklist items unique to that ecosystem
- [ ] A CLI version of the checklist for terminal-first workflows
- [ ] Printable / PDF export of the checklist for offline or paper-based reviews
- [ ] More framework-specific templates (Notion, Linear, Jira, GitHub Projects already exist — Asana and ClickUp are next)

## Exploring

- [ ] A lightweight browser extension that surfaces the relevant checklist section based on the files changed in a PR
- [ ] Community-submitted "annotated review" examples beyond the current one

Have an idea that's missing here? [Open an issue](https://github.com/projekta2/pr-review-canvas/issues) — this roadmap is shaped by people actually using the checklist, not decided in isolation.
